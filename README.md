One line, the funniest weather forecast for a city that does not exist, for the
[make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf).

## The line

> In Grumblewick, tomorrow: light rain, a 60% chance of Tuesday again, and one umbrella filing for divorce.

## How it works

`main.py` (Python stdlib only) writes exactly that one line to
`/output/entry.txt`. It asserts the line is 1–120 characters, a single line,
with no leading or trailing whitespace, and is deterministic: every run
produces the same bytes.

```sh
python3 main.py
```
